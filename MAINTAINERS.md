The maintainer coordinates releases, reviews contributions, triages issues, and
handles security and conduct reports. Ownership for all repository paths is
declared in [.github/CODEOWNERS](.github/CODEOWNERS).

## Contribution and review policy

Community changes should come from a fork through a pull request targeting `main`.
The project policy is one code-owner approval before merging community changes,
passing applicable checks, and resolving review comments. See
[CONTRIBUTING.md](CONTRIBUTING.md) for the workflow.

`CODEOWNERS` identifies reviewers. Mandatory approvals and restrictions on direct
pushes require separate GitHub branch-protection or ruleset settings; the file
alone does not enforce them. These documents describe the contribution policy
and do not assert that those settings are enabled.

Additional code owners must agree to the role and have write access to this
repository before being listed. Ownership changes should be recorded in a pull
request updating both this file and `CODEOWNERS`.
